# 演講紀錄→教學網站：可重用提示範本

替換活動、讀者、照片數、repo及驗收條件後使用。只需選擇目前階段，不必每次貼全部。明確發布授權不會取代帳號權限或工具要求。

## 最短版本

我要把演講照片與筆記做成繁體中文GitHub Pages教學網站，含全部原圖、我的歷史與人文教學反思，以及官方學習資源。先逐筆紀錄，等我說「開始製作」再整合並發布到[repo網址]。保留原文與修正，區分講者觀點、我的心得與查核補充。完成時驗證照片、連結與公開網址，並保存對話紀錄及合作分析；公開版排除憑證。

## 01｜演講開始前：先建立紀錄模式

```text
我要把今天的演講製作成繁體中文教學網站，最後發布到 GitHub Pages。
活動：2026-10-13，中央氣象署，張慶瑞老師量子演講；整理者：陳達毅。
讀者：有科學背景、想理解量子科技與開始實作的教師及研究者。

接下來我會分批傳照片、講者重點與自己的心得。現在先進入「紀錄模式」：
1. 每則編號，保留文字原文及照片原始檔；建立照片清單，回報成功讀取與缺漏。
2. 分開標示「講者觀點、我的心得、待查核、編輯補充」。姓名修正統一用在正文，原始紀錄保留修正過程。
3. 每輪簡短回覆新增內容與素材累計；有無法判讀或照片缺漏才指出，不反覆產生全文。
4. 我說「開始製作」後，再整合網站；同步保留可見對話和需求清單。
此階段不發布。
```

## 02｜演講結束後：把成果與驗收說清楚

```text
開始製作。請依已提供的照片與筆記完成並發布網站。

目的與讀者：讓教師、科學研究者理解演講重點，並找到開始學量子計算的路線。
內容：演講紀錄、科學史、人文與第一人稱教學反思、量子計算／通訊／感測、氣象的量智融合研究，以及官方學習資源與實作方法。
主線：從歷史看未來；「量子電腦放在你面前，你會用嗎？」；如何把精彩演講轉化成日常教學。
素材：本次預期20張原始照片，先核對清單；全部放入可瀏覽的相簿，保留原尺寸與下載。照片按拍攝場景時間排序，對話保持訊息順序。
編輯：保留我的心得口吻；科學描述需查核，補充資料附來源。區分講者預測、研究方案、我的心得和已查核結論；看不清楚的人名不猜。
設計：手機和桌機都能閱讀；文中搭配照片、章節導覽與完整相簿；簡潔的繁體中文科學人文風格。
紀錄：另做對話原文、合作分析及可重用提示範本，能從網站進入並下載；說明原文可取得的範圍，公開內容排除憑證。

發布：使用已連接的GitHub工具，更新 https://github.com/oceanicdayi/2026_1013_quantum_talk 的main；沿用現有GitHub Pages。這次已授權發布上述內容。
驗收：列出收錄照片數；檢查內部連結、原檔完整性、互動的基本計算；確認最新Pages建置成功、公開首頁與新頁面可讀取，最後提供網址及檢查結果。
合理的版面選擇請自行完成；只在缺少必要素材、存取權限或關鍵歧義時集中提問。工具無法完成的部分，說明具體阻礙，不把檔案推送當作網站已發布。
```
