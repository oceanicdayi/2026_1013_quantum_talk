# 從演講筆記到教學網站：對話分析與合作方法

本分析以2026-10-13本次可見對話U01–U28、發布過程中可見的3筆助手回覆，以及可驗證的專案成果為依據。這是單一案例的流程回顧，沒有A/B比較或完整耗時統計，不能宣稱某一提示會固定節省幾成時間或保證每次成功。

## 最值得改變的一件事

在第一則訊息先說明最後要交付「什麼成果、給誰使用、如何驗收、發布到哪裡」。照片與短句仍然可以邊聽邊傳。這次真正決定網站風格和內容深度的，是U26對歷史、人文、科學教育與第一人稱反思的描述；下次可提前用兩三句寫出這個主線。

你不需要先寫好完美提示，也不必把現場筆記改成長文。助手應把零散材料整理成清單、維護修正與待查核項目；必要時集中釐清重要歧義。要求清楚能提高可核對性，工具權限與素材讀取問題仍需要實際處理。

## 將內容來源標示清楚

以下分類能避免把聽講心得、講者預測與編輯補充混在一起。標籤是低負擔的建議，不是每則訊息的必填表格。

| 類型 | 本次例子 | 網站處理方法 |
| --- | --- | --- |
| 講者觀點／預測 | 量子與AI結合、Q-Day時間、學習約2–3年 | 署名或標示估計，保留不確定性 |
| 個人心得 | 薛丁格的故事震撼；希望上課同樣精彩 | 保留第一人稱與教育反思，不改成一般科普摘要 |
| 待查核 | 洪教授全名、研究成效、臺灣投入數字 | 列為未確認，先寫已知部分；不猜全名、不補造數據 |
| 編輯補充 | 量子態、官方課程、12週練習、教案 | 附可靠來源，明確說明是另外增加的學習內容 |

例如U08「破解金融加密」適合作為演講索引，但寫成文章時需說明Shor演算法、可用容錯量子電腦與特定密碼體系等條件。U26的「相同結果」則應保留為原始心得，正文補充量子實驗可重現的統計分布與誤差。這些例子說明原文保存與科學編輯可以同時完成。

## 建議採用四個階段

1. **採集**：說明最終用途，進入紀錄模式；傳照片＋短筆記，助手編號、核對附件、追蹤修正。每輪短回覆即可。
2. **整合**：說「開始製作」，交代讀者、內容主線、個人心得、來源要求與驗收條件。助手先完成素材對照和需求清單，再製作。
3. **檢查與發布**：核對照片總數、缺漏、文字歸屬、連結與互動；使用可用權限發布，確認建置成功和公開網址實際可讀取。
4. **保存與接續**：保存原文可取得範圍、照片對應、需求與工作摘要。下次給repo及要改的項目，讓助手讀現況後繼續。

初始的讀者與風格不用每輪重寫；新增需求只要指出修改處。若開場指定「先紀錄、不發布」，助手應等製作指令；若已明確授權完成與發布，例行版面決策不需逐一詢問。這個指令不能繞過必要的帳號存取、工具限制或平台要求。

## 把完成定義成可以核對的條件

- **素材**：預期張數＋實際取得張數＋可回查檔名。照片原始檔保留，公開相簿每張都能開啟；縮圖可以另外產生，不能取代原圖。
- **內容**：演講紀錄、歷史主線、個人心得與額外資源各自可辨認。每項重要修正已套用正文，原始對話留痕。
- **網站**：手機／桌機版面、內部跳轉、下載及互動有適當檢查；無法做視覺檢查時，據實標示範圍，不宣稱已做。
- **發布**：指定repo和分支；GitHub Pages最新建置成功，首頁、新頁與資產實際可讀取。推送commit不代表自動完成全部發布。
- **留存**：對話紀錄、協作分析、提示範本可從頁面進入並下載。權限／憑證狀態可描述，值不放入公開檔案。

## 下次最省力的訊息格式

現場使用「編號｜來源類型｜一句內容｜對應照片」即可。例如：

> P14｜講者觀點｜量智融合：傳統AI加入量子分析。照片為研究架構，尚未核對是否有驗證成果。

修正使用「更正：原文→新文；套用範圍」。修改網站使用「位置＋目前問題＋希望結果＋驗收方式」。這讓助手能定位和核對，不需要再從大段重述中推測差異。

較長工作或新對話則提供專案網址、目前檔案、完成項目和剩餘需求。保存在repo的紀錄可作為接續依據；公開對話紀錄不等於ChatGPT平台內的完整聊天匯出或永久記憶。

## 助手也應負責的工作

助手應主動整理素材清單、維護需求與修正、查核可變事實與科學描述、辨識缺少的照片或權限，以及分開回報「檔案已推送」和「網站已可用」。圖片讀取失敗與Pages權限問題，需要由助手描述具體狀態並在可用工具內解決，不能要求使用者以更華麗的提示替代這些實際工作。

## 範本及參考

四份可直接修改的提示範本見[prompt-templates.md](prompt-templates.md)。最短版本如下：

我要把演講照片與筆記做成繁體中文GitHub Pages教學網站，含全部原圖、我的歷史與人文教學反思，以及官方學習資源。先逐筆紀錄，等我說「開始製作」再整合並發布到[repo網址]。保留原文與修正，區分講者觀點、我的心得與查核補充。完成時驗證照片、連結與公開網址，並保存對話紀錄及合作分析；公開版排除憑證。
